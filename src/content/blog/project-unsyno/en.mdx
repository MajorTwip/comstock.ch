- **Migrate mail**
  - [x] Set up Gmail Enterprise mail
  - [x] Migrate SMTP

- **Migrate data**
  - [ ] Set up external disk bay
  - [ ] Install TrueNAS
  - [ ] Triage data to the new storage

  - [ ] Loki

  - [ ] MySQL

  - [ ] Join DSM to the IdP

  - [ ] Build hardware
  - [ ] Set up TrueNAS
